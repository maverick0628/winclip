# WinClip Brand Assets

Production-ready brand asset system for WinClip — Direction D (`[WinClip]` wordmark with teal selection brackets).

## Quick reference

| Surface | File |
|---|---|
| App icon (.ico bundle) | `app-icon/WinClip.ico` |
| App icon PNGs (16–256) | `app-icon/png/icon-*.png` |
| Microsoft Store tiles | `store-tiles/*.png` |
| System tray (dark Windows theme) | `tray/tray-white.ico` |
| System tray (light Windows theme) | `tray/tray-dark.ico` |
| System tray (active state) | `tray/tray-active.ico` |
| Inno Setup wizard banner | `installer/WizardImage.bmp` |
| Inno Setup header strip | `installer/WizardSmallImage.bmp` |
| Installer .exe icon | `installer/setup-icon.ico` |
| Web favicon | `web/favicon/favicon.ico` |
| Apple touch icon | `web/favicon/favicon-180.png` |
| OG / social card | `web/og-image.png` (generated by the pipeline, not committed) |
| WPF splash | `in-app/splash.png` |
| About dialog header | `in-app/about-header.png` |

## Color tokens

- Primary accent (teal): `#2DD4BF`
- Primary hover: `#14B8A6`
- Background (deepest): `#0B1220`
- Surface: `#0F172A`
- Elevated: `#1E293B`
- Text primary: `#E2E8F0`
- Text secondary: `#94A3B8`

## Typography

- **Brand wordmark:** Satoshi 700 with `letter-spacing: -0.02em`
- **Brackets:** Satoshi 500 at 105% size (slightly larger than the body)
- **`W` glyph:** Satoshi 900

Source: [Fontshare — Satoshi](https://www.fontshare.com/fonts/satoshi).

## Regenerating assets

If a tweak is needed (color, glyph weight, layout), update the canonical source
in `source/` or `render-templates/`, then re-run the pipeline:

```powershell
cd brand/_pipeline
node render.js          # rebuild all PNGs from templates
python bundle.py        # rebuild ICOs and BMPs from PNGs
```

The pipeline takes ~30 seconds.

## Preview

Open `brand/index.html` in a browser to see every asset in context — tray strips,
Store tiles, installer wizard, OG card, etc.

## Directory layout

```
brand/
├── source/              # Canonical SVG masters
├── render-templates/    # HTML templates rendered by Puppeteer
├── _pipeline/
│   ├── render.js        # Puppeteer → PNG pipeline
│   ├── bundle.py        # PNG → ICO + BMP bundler
│   └── package.json
├── app-icon/
│   ├── WinClip.ico
│   └── png/             # Individual sizes
├── store-tiles/         # Microsoft Store package assets
├── tray/
│   ├── tray-*.ico       # Multi-resolution bundles
│   └── transparent/     # Individual PNGs
├── installer/           # Inno Setup BMPs + .ico
├── web/                 # Favicons (the OG card is generated here by the pipeline)
└── in-app/              # Splash + about dialog
```

## Where to wire each asset

### .NET / WPF app
- `WinClip.csproj` → `<ApplicationIcon>brand/app-icon/WinClip.ico</ApplicationIcon>`
- Tray icon (WinForms `NotifyIcon`) — load `tray/tray-white.ico` or `tray/tray-dark.ico` based on `SystemParameters.HighContrast` and registry probe
- Splash → `in-app/splash.png`
- About dialog header image → `in-app/about-header.png`

### Microsoft Store package (`WinClip.Package/Assets/`)
Copy every file from `store-tiles/` into the package's Assets folder — file names already match the manifest's logo references.

### Inno Setup (`installer/WinClipSetup.iss`)
```ini
[Setup]
SetupIconFile=brand\installer\setup-icon.ico
WizardImageFile=brand\installer\WizardImage.bmp
WizardSmallImageFile=brand\installer\WizardSmallImage.bmp
```

### Website (`duncansmith.tech/apps/winclip/`)
```html
<link rel="icon" type="image/x-icon" href="/favicon.ico">
<link rel="icon" type="image/png" sizes="32x32" href="/favicon-32.png">
<link rel="apple-touch-icon" sizes="180x180" href="/apple-touch-icon.png">
<link rel="manifest" href="/manifest.json">
<meta property="og:image" content="/og-image.png">
<meta name="twitter:card" content="summary_large_image">
```
